# Creator-led resource video

A reusable skill for planning original founder/creator-led short videos that
teach something useful and promote a real free resource or giveaway.

## Use it when

You need an original script, beat/shot plan, captions, or a generation brief for
a creator-led tutorial, product walkthrough, free-resource promo, or legitimate
giveaway. Bring the actual offer, relevant creator context, approved likeness/
voice assets, and any source references you have permission to use.

## Included

- `SKILL.md` — task routing, production workflow, safeguards, and deliverable
  checklist.

The skill uses broad, reusable structure; it does not reproduce a specific
creator's exact wording, voice, film, or edit. It does not imply that a reference
was AI-generated or that a giveaway exists without evidence.
